# وثائق تصميم بنية محرر Luma Editor (Architecture Design Docs)

مرحباً بك في وثائق التصميم الهندسي لمحرر **Luma Editor**.  
هذا المحرر مبني على فلسفة معمارية غير تقليدية لمحررات محرك **Bevy**: **محرر مبني بالكامل على الـ Node Graph من البداية إلى النهاية**، مع ميزة التوسع والغوص داخل العقد (**Contextual Focus / Dive-In Mode**).

## المبادئ الأساسية للتصميم

1. **Pure Core (نواة نقية):** طبقة البيانات لا تعتمد على الـ UI أو تفاصيل الرسم، مما يجعلها قابلة للاختبار (Unit Tests) بنسبة 100%.
2. **Deterministic State (حالة حتمية):** أي عملية في المحرر تمر عبر نظام المعاملات لضمان إمكانية التراجع الكامل (`Undo/Redo`).
3. **Single Responsibility Workspaces:** كل نود هو بمثابة "محرر متخصص مصغر" يعزل الأدوات غير المرتبطة بمهمته.
